# PDF Column Search (Vite + React)

Client-side app to search values under a column named "Nama" inside PDF files using pdfjs. Fast, runs entirely in the browser.

Quick start:

1. Install:

```bash
npm install
```

2. Run dev server:

```bash
npm run dev
```

Open the app at the printed dev URL. Upload a PDF, type the name to search, then click Search.
